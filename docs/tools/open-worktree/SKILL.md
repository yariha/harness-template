# 워크트리 초기화

새로 만든 워크트리를 로컬 개발이 가능한 상태로 맞춘다.
환경 파일 복사, 의존성 설치, 로컬 DB 초기화(있다면) 선택 분기를 순서대로 처리한다.

## STEP 0 - 절대 실행 조건

이 스킬은 반드시 격리된 작업트리 안에서만 실행한다.
루트 소스 트리, 특히 `main` 브랜치가 체크아웃된 원본 트리에서는 절대 실행하지 않는다.

1. `git rev-parse --show-toplevel`로 현재 위치가 대상 워크트리인지 확인한다.
2. `git worktree list --porcelain`으로 원본 루트가 아닌지 확인한다.
3. 현재 루트가 `.codex/worktrees/` 또는 `.claude/worktrees/` 아래가 아니거나 `refs/heads/main` 워크트리라면 즉시 중단한다.
4. 중단 시에는 파일 변경, env 복사, 설치를 하지 말고 "격리된 작업트리로 이동한 뒤 다시 실행해야 한다"고만 안내하고 종료한다.

원본 `main` 워크트리는 env 파일을 읽는 용도로만 사용한다.

## STEP 1 - 실행 순서

1. 사용자에게 구축할 개발 환경을 묻는다. (예: A. 로컬 DB / B. 스테이지 DB / C. 프로덕션 DB) 선택지 문안은 프로젝트에 맞게 고정 텍스트로 둔다.
2. 선택에 따른 대상 env 파일을 원본 워크트리에서 각 앱 경로로 복사한다. 복사 전 대상 존재 여부를 확인하고 덮어쓸지 묻는다.
3. `pnpm install --frozen-lockfile`을 워크트리 루트에서 실행한다.
4. 생성물이 필요한 앱(예: ORM client)은 generate를 실행한다.
5. 로컬 DB 옵션이면 로컬 DB 초기화 절차(별도 문서)를 따른다.

## 종료

복사한 env, 설치 결과, 다음에 실행할 dev 명령을 한 번에 보고한다.
