# Workflow Tools

> 반복 가능한 agent workflow와 보조 로그의 시작 문서다.

## 유의사항

이곳의 workflow 정의는 기본적으로 인간이 직접 수정한다.
단, 사용자가 명시적으로 workflow 실행/갱신을 요청한 경우 `RESEARCH.md` 같은 실행 로그와 낡은 라우팅 문구는 갱신할 수 있다.
